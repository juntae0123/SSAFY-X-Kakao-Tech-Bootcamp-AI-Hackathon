## 🛠️ 로컬 실행 방법

```bash
# 1. 레포 클론
git clone https://github.com/juntae0123/SSAFY-X-Kakao-Tech-Bootcamp-AI-Hackathon.git
cd SSAFY-X-Kakao-Tech-Bootcamp-AI-Hackathon/choose_topic/agri_fetch_scripts

# 2. 패키지 설치
pip install -r requirements.txt

# 3. 환경변수 설정
cp .env.example .env
# .env 파일 열어서 본인 API 키 입력

# 4. 데이터 수집 실행
python fetch_all.py
```
